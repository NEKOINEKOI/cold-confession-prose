# 改写协议（主流程 · 八步）

> 路由：本文件是**改写任务的主文件**。用户给故事 → 走这八步 → 出成品。
> 前置：已在 SKILL.md 定好强度档。技法细节查 `techniques.md`。
> 本文件所有示例取自一次真实改写（素材：用户"被 AI 抄家"经历），用于说明每一步**怎么从素材里找**。

---

## 第 1 步 · 定档

| 档位 | 取用技法 | 选档信号 |
|---|---|---|
| 轻度 | 冷静语气 + 动作留白 + 少量数字 | "稍微冷一点" |
| **标准**（默认） | + 数字锚定 + 母题 ≥2 次 + 时间跳切 + 第三方装置 | 完整经历要改写 |
| 强风格 | + 五幕 + 母题进化 ≥3 次 + 工序段落 + 残缺结尾 | "复刻那种质感" |

档位决定**用量**，不决定**原则**（SKILL.md 七条声音原则恒定）。

---

## 第 2 步 · 素材二分：删掉所有"议论"

把用户素材逐段标成两类：

| 类型 | 内容 | 处理 |
|---|---|---|
| **叙事** | 发生了什么（时间、地点、动作、物件、数字、对话） | **保留**，这是改写原料 |
| **议论** | 你悟到了什么（感悟、比喻、道理、建议、金句） | **全部删除** |

**为什么**：本类文体靠母题收口制造余味。作者一跳出来讲道理，张力当场泄掉。

**该删的议论类型**（素材里出现一律删）：

| 类型 | 典型句式 |
|---|---|
| 人生感悟比喻 | "人生就像……""失去后才懂得珍惜" |
| 时代感慨 | "这个时代……""我们这代人……" |
| 身份自况 | "作为一个一人公司……""做了十年产品我深知……" |
| 行动建议 | "大家一定要备份""建议你们也……" |
| 点题金句 | "有些东西，只有失去了才知道珍贵" |

**替换手法：把议论改写成事实。** 这是本类文体的标准动作——不告诉读者道理，只把事情摆出来。

> 素材议论："可事实是，服务器并不一定永远都在。"
> 删除议论，改写成事实："今年 4 月 So//ra 停服，所有作品从平台上消失了，就像从来没来过。"

---

## 第 3 步 · 数字标级（纪实轨生命线）

把素材里每个数字标成 `[确切] / [约数] / [未知]`：

| 级别 | 处理 | 示例 |
|---|---|---|
| **[确切]** 素材写明 | 直接用 | 2500 篇、7000 个文件、5 分钟快照 |
| **[约数]** "100 多 G"这类 | 保留约数或取整，**不要精确化** | "D 盘瘦了 100 多 G" |
| **[未知]** 素材没写 | **模糊化，不要填数** | 见下 |

**模糊化写法库**：
- "我数到第二十几个就懒得数了"
- "我懒得数"
- "不知道多少次"
- "前后大概……"

**为什么模糊化不是偷懒**：它多交付一层钝感人格。一个连自己被按了多少次都不数的人，比精确报出"47 次"的人更冷。

**一票否决**：编造素材里没有的精确数字（"47 次允许""11 个图标"），直接判不合格。
**约数也不得精确化**：素材说"100 多 G"，成稿就不能写"103GB"——性质等同于编数字。

> 本例处理：素材只说"按烦了""到处都是白板 icon"，没给次数。
> 改写：`我点了不知多少次允许` → `后来我想数，数到第二十几个就懒得数了。`
> 这是**模糊化**，不是编造。

---

## 第 4 步 · 挑母题，画轨迹表

从素材里找那个"**反复出现、且能在结尾以失效 / 还在 / 忘了的形态回来**"的物件或动作。

**判断标准**：它本身是不是就是主题的隐喻？

> 本例：软件都没了，但代表软件失效的白板图标还在 → 完美的残缺化母题。
> 主题是"东西消失了"，母题是"消失留下的痕迹比消失本身更顽固"。

**轨迹表模板**（动笔前填完）：

| 次 | 位置 | 形态 | 这次带什么新信息 |
|---|---|---|---|
| 1 | 中段 | 埋下 | 因果：每死一个软件，多一个图标 |
| 2 | 靠后 | 量变 | "比软件还多" |
| 3 | 结尾 | 反讽 | 其中一个是我上周建完就忘了的，它还在 |

**不及格**：出现三次都是同一个意思（"11 个 → 消失 → 11 个没回来"），那叫**复读**，不叫母题。
**及格**：每次回扣带新事实 / 新因果 / 新工艺 / 反讽。

> 本例三次回扣：
> 1. `桌面上软件开始一个一个失效。每死一个，多一个白板图标。`（新因果）
> 2. `桌面上多出来的白板图标，比软件还多。`（量变）
> 3. `白板图标，我懒得数。其中一个，是我上周想画架构图、建完就忘了的。它还在。别的都没了。`（反讽 + 残缺化）

---

## 第 5 步 · 找第三方：谁替"我"做了决定

在素材里找：有没有一个**工具 / 系统 / 人**，替"我"做了本该自己做的决定？

**这往往是全文最锋利的一根刺，通常就是主题本身。**

> 本例：删文件的是 AI，让我关机的也是 AI。
> 主题讽刺 = "决定权不在我手里"。

**模板**：
```
[第三方]说，[本该由我做的决定]。[我照做了]。
从头到尾，没有一个决定是我自己做的。
[删/做]的是它，[告诉我怎么收场]的也是它。我只是在旁边，[动作]。
```

**用浅的征兆**：删掉第三方，故事照样能讲 → 说明它没起作用，必须升格。
第三方不能只承担功能（"我用了 X 工具"），要**揭示人格的被动**。

---

## 第 6 步 · 工序化：找一个"手在动"的场景

扫描素材，找任何"手在动"的环节——操作、修复、整理、调试、照顾、收拾。把它写成 SOP。

**为什么这招最致命**：缺了它，全文从"织物质感"掉到"事故复盘"。这是单项里最致命的失分。

**句式骨架**：
```
先是[工序1]，[工序2]，[工序3]，要[方向/禁忌]。
[做完]举起来[对着光/屏幕]看一看，再接着[下一道]。
```

> 本例（素材里"用了两个恢复工具，全坏了"）：
> `我用两个工具找回。先是 R-Studio 扫分区，扫完举到屏幕前看一眼，再换 Windows File Recovery 扫一遍。先是快速，再深度，最后把认出来的文件名一个一个对着看。`
>
> 素材原文只有一句"前后用了两个恢复工具，流程都足够顺利"——**把它拆成工序，是这一步的核心动作**。

---

## 第 7 步 · 调性扫描

通读一遍，逐项搜：

| 搜什么 | 处理 |
|---|---|
| 网络梗、俏皮话、自嘲谐音 | 删掉，或抽梗保事实 |
| "然而 / 但是 / 所以 / 因为" | 能删就删，改句号硬断 |
| 形容词堆砌（"奢华的酒店"） | 换成具体名词（酒店名） |
| 同义钝感句堆叠 | "懒得数"后紧跟"我没有慌"会显刻意，要隔段 |

**抽梗保事实**（保留信息、抽掉腔调）：

> 素材原句：`之前初代目龙虾都没把我怎么样，栽到了龙虾 n 代目。`
> 改写：`更早那次事故，也没伤到我。这次不一样。`
> ——保留"以前安全、这次翻车"的对比，抽掉网络梗。

**注意**：如果用户的品牌人设本来就靠口语梗，交付时必须提示可选**混合版**（保留骨架技法，语气回原声）。

## 第 8 步 · 结构：篇幅与情绪成反比

| 部位 | 篇幅 | 写法 |
|---|---|---|
| 开头 | 极短 | 数字锚 + 结局钩子 |
| 回忆 / 铺垫 | 中 | 可跳切 |
| 慢板细节 | 长 | 工序、物件、对话，可以慢慢写 |
| **高潮** | **最短** | 只给几段，全用动作和数字，不解释情绪 |
| 余韵 | 最长 | 回到母题，慢下来 |

**结尾两条路**：

| | 母题收口（唯一正确） | 议论升华（禁止） |
|---|---|---|
| 做法 | 回到开头意象，以"失效 / 还在 / 忘了"形态收尾，**不解释** | 拔高到人生 / 时代 / 道理，给感悟或建议 |
| 效果 | 判断权交给读者，余味长 | 说教感，张力泄掉 |

> 本例结尾（母题收口，零议论）：
> `我把那台电脑又开起来过一次。桌面上多出来的白板图标，比软件还多。`
> `我关掉桌面。它们还在。`
> `我留着那个上周建的、忘了的架构图文件。它打不开，但还在。`

## 10 分制自检表（标准档与强风格档打分；轻度档只做定性检查）

| # | 项目 | 分值 | 满分标准 |
|---|---|---|---|
| 1 | **工序式亲密**（S） | 2 | 至少一段把操作写成 SOP：工具名 + 分步 + 观察动作 + 方向/禁忌 |
| 2 | **母题进化**（S） | 2 | ≥2 母题、≥3 次出现，**每次带新信息**，结尾残缺化或反讽化 |
| 3 | **第三方装置**（S） | 2 | 第三方替"我"做决定，且点透"决定权不在我手里"的讽刺 |
| 4 | 数字锚定（A） | 1 | 有同量纲量级对比；情绪换成计量单位；无空洞形容词 |
| 5 | 对比倒置（A） | 1 | ≥1 处倒置，且逻辑不生硬 |
| 6 | 冷叙述留白（A） | 1 | 高潮最平；有失态/顿悟留白句；未堆叠同义钝感句 |
| 7 | 结构节奏（B） | 0.5 | 篇幅与情绪成反比；有非线性跳切 |
| 8 | 句法纯度（B） | 0.5 | 几乎无"然而/但是/所以/因为"；关键反转用最短句 |
| 9 | 结尾纯净度（B） | 0.5 | 母题收口；无升华、感悟、建议、金句 |
| 10 | 调性统一（B） | 0.5 | 无网络梗/俏皮话；人格温度一致 |

**评级**：9-10 可交付（强风格档目标）；7-8 骨架成立、按缺失的 S 级补写（标准档目标）；≤6 重写。

**一票否决项**（触犯直接判不合格，不计分）：
- [ ] 是否**在用户没给素材的情况下自己编了故事**？
- [ ] 是否编造了素材中没有的数字？
- [ ] 是否把约数精确化（"100 多 G" → "103GB"）？
- [ ] 是否编造了对话原话、他人行为细节、不确定的时间？
- [ ] 未知数字是否已走模糊化？
- [ ] 是否复用了参考作品的独特句子、母题组合、情节顺序？

**评分输出格式**：
```
自评：X/10（档位：标准 / 强风格）
- 工序式亲密 X/2 —— 理由
- 母题进化 X/2 —— 理由
- 第三方装置 X/2 —— 理由
- 4-10 项合计 X/4 —— 一句话总结
否决项：通过 / 触犯：xxx
保留与改动：哪些是素材原话、哪些数字做了模糊化
下一步：可交付 / 需补哪几项
```

## 常见失分点 Top5

| # | 失分点 | 症状 | 药方 |
|---|---|---|---|
| 1 | **工序式缺失** | 读起来像事故复盘 / 工作日志 | 找一个"手在动"的场景，写成 SOP |
| 2 | **母题是复读不是进化** | 出现三次，读者没获得新信息 | 每次回扣安排新因果 / 新事实 / 新工艺 / 反讽 |
| 3 | **第三方用浅** | AI 只承担功能，不揭示人格 | 补一句点透被动 |
| 4 | **调性破洞** | 冷叙述里冒出网络梗 / 谐音梗 | 抽梗保事实 |
| 5 | **编数字** | 为凑数字锚造出"47 次""11 个" | 走模糊化策略 |
