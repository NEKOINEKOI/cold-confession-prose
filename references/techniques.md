# 技法库（九招）

> 路由：改写时按需查阅。主流程在 `rewrite-protocol.md`。
> 每招给出：**怎么从用户素材里发现它** + 模板 + 迁移示范。
> 迁移示范**只共享机制，不共享句子**——照搬示范句属于换皮复刻。

---

## 取用对照表

| 技法 | 级 | 轻度 | 标准 | 强风格 |
|---|---|---|---|---|
| 数字锚定 | A | 少量即可 | 是 | 是 + 开头量级对比 |
| 对比倒置 | A | 可选 | 是 | 是 |
| 冷叙述留白 | A | **是**（本档核心） | 是 | 是 |
| 非线性跳切 | A | 否 | 结局钩子即可 | 完整跳切 |
| 工序式亲密 | **S** | 否 | 可选 | **必做** |
| 母题复现 | **S** | 否 | ≥2 次 | ≥3 次且**每次带新信息** + 结尾残缺化 |
| 第三方装置 | **S** | 否 | 是（点出被动） | 是（升格为全文脊梁） |
| 真实锚点 | B | 顺其自然 | 每场景 ≥1 | 每 300 字 ≥1 |
| 称呼陌生化 | B | 否 | 慎用 | 可用 |

**为什么分 S/A/B**：S 级是"签名招"——缺了立刻露怯，读起来像事故复盘而不是这种文体。A 级构成骨架。B 级是装饰，可省。

**时间有限时**：优先保住 S 级的"第三方装置"和"母题"，比堆数字有效得多。

---

## S1 · 工序式亲密

- **定义**：把操作 / 照顾 / 修复行为拆成步骤，用"先 X 再 Y 最后 Z"，冷感中透出温度。
- **怎么在素材里找**：任何"手在动"的环节——整理、扫描、修复、调试、收拾、照顾、教学。素材里一句"我用了两个工具"就是一个待拆的工序段。
- **模板**：`[主体]把[对象]放在[位置]，[动作]。先是[工序1]，[工序2]，[工序3]，要[方向/禁忌]。`
- **迁移示范**（题材与本例无关，仅共享机制）：
  > 她把我的手放在她腿上，一根一根磨。先是粗的那一面，磨完换一面，再换一面。磨一会儿举起来对着灯看看，再接着磨。她说，这一面磨形状，这一面抛光，最后一面不要来回蹭，要顺着一个方向。
- **缺失后果**：全文从"织物质感"掉到"事件复盘"。单项里最致命的失分。

## S2 · 母题复现与进化

- **定义**：选 2-3 个意象隔段回扣，**每次回扣必须带新信息**。只重复同一含义的叫"复读"。
- **怎么在素材里找**：找那个反复出现、且能在结尾以"失效 / 还在 / 忘了"形态回来的物件或动作。自问：它是不是主题的隐喻？
- **不及格**：图标出现三次都是"11 个 → 消失 → 11 个没回来"，含义没长。
- **及格**：`每死一个软件多一个白板图标`（新因果）→ `比软件还多`（量变）→ `其中一个是我上周建完就忘了的，它还在`（反讽 + 新信息 + 残缺化）。
- **模板**：开篇埋母题 A → 中段让 A 在异地 / 异物上重现 → 某次回扣带出新事实或新因果 → 结尾以"失效 / 残缺 / 反讽"形态收。
- **动笔前**：列"母题轨迹表"，逐次规划「位置 / 形态 / 这次带什么新信息 / 结尾如何残缺」。

## S3 · 第三方装置

- **定义**：引入一个真实工具 / 系统 / 人作为"第三方判决"或"逃避代理"，替"我"做出本该自己做的决定。
- **怎么在素材里找**：问一句——**这件事里，有没有谁替你做了本该你自己做的决定？** 答案往往就是全文主题。
- **进阶（强档必做）**：不只让它做决定，要**点透讽刺**——"删文件的是它，告诉我关机的也是它。我只是在旁边点了不知多少次允许。"把"决定权交出去"从背景升格为全文脊梁。
- **模板**：`[第三方]说，[本该由我做的决定]。[我照做了 / 我盯着那行字看了很久]。从头到尾，没有一个决定是我自己做的。`
- **用浅的征兆**：删掉第三方，故事照样能讲 → 说明它没起作用。

## A1 · 数字锚定

- **定义**：用具体数字替代形容词。
- **怎么在素材里找**：想写"很大 / 很久 / 很痛"时，先问"这能换算成什么数字"。素材里已经有的数字优先用。
- **模板**：
  - 量级对比：`[极小单位]的重量，[数字]。[极大单位]的重量，[数字]。`（两句必须**同量纲**才可比）
  - 沉默量化：`[N] 秒` / `[N] 下` / `[N] 次`
- **红线**：纪实轨必须用素材真实数字或模糊化，**禁止编造**，**约数不得精确化**（见 rewrite-protocol 第 3 步）。

## A2 · 对比倒置

- **定义**：把该当背景的捧成主体，把该当主角的按进背景。
- **怎么在素材里找**：找一对"该大 / 该小"的关系，反过来写。素材里最锋利的矛盾通常就是倒置点。
- **模板**：`[一堆大物]就像[一堆物]一样被请来做了陪衬，[他们不知道为什么出现]，[什么都没发生]。`
- **变体**：
  - 尊严倒置（小人物"像讨论一项工艺"，大人物"不知道自己为什么出现"）
  - **权限倒置**（申请的是查看，干的是删除）——这是最锋利的一种，把矛盾压缩在一句话里。
- **触发**：需要新鲜感、或需要点透荒诞时。

## A3 · 冷叙述留白

- **定义**：情绪顶点处强制删光形容词，只剩动作 / 数字 / 一句话。
- **模板**：
  - 失态留白：`我没有[情绪词]。我一直在等自己[情绪词]。`
  - 顿悟留白：`我想，原来是这样。`（≤8 字）
- **使用注意**：不要把两个同义钝感句堆在同一段（"懒得数"后紧跟"我没有慌"会显刻意），要隔段使用。
- **触发**：写到情绪顶点时——这是全文最该收、也最容易写砸的地方。

## A4 · 非线性跳切

- **定义**：先写"现在 / 结局"钩子 → 插叙早年起点（形成反差）→ 回到现在主体 → 高潮靠近结尾且极短。
- **怎么在素材里找**：素材如果本身是顺叙，把结局（或最具冲击力的那个画面）提到最前面当钩子。
- **档位**：标准档做"结局钩子"即可，强风格档做完整跳切。

## B1 · 真实锚点

- **定义**：可查的真实名词（品牌 / 地名 / 年份 / 型号），把叙事钉成"像真事"。
- **纪实轨**：素材里天然存在，不用硬塞。
- **优先级最低**，不要为凑锚点破坏节奏。

## B2 · 称呼陌生化

- **定义**：让对方提出不合常理的称呼 / 规则，叙述者照做；称呼同时含顺从与掌控的矛盾。
- **纪实轨慎用**——真实关系里硬造称呼会失真。

## 反模式速查

| 反模式 | 改法 |
|---|---|
| 用连接词串联 | 改句号硬断 |
| 高潮处解释情绪 | 删形容词，只留动作与数字 |
| 结尾讲道理 / 给建议 | 改母题收口 |
| 不同题材写出来都一个样 | 降档，或换母题与人格 |
| 换题材但读着像范文换皮 | 检查是否复用了原作的句子、母题组合、情节顺序 |
| 堆形容词代替名词 | "奢华的酒店" → 具体酒店名 |
| 用可指认的真实人物做虚构叙事 | 换成不可识别的虚构人物 |
