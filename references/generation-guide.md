# 生成与改写指南

> 路由：本文件供**模式 B（原创生成）**与**模式 C（改写润色）**使用。分析任务不要读。
> 前置：先在 SKILL.md 选好模式与强度档。本文中标记为【强】的技法仅在强风格档要求，【标】为标��档起要求，【轻】为任何档都可保留。

---

## 一、技法清单（按强度档取用）

| 技法 | 级 | 轻度 | 标准 | 强风格 |
|---|---|---|---|---|
| 数字锚定 | A | 少量即可 | 是 | 是 + 开头量级对比 |
| 对比倒置 | A | 可选 | 是 | 是 |
| 冷叙述留白 | A | **是**（本档核心） | 是 | 是 |
| 非线性跳切 | A | 否 | 结局钩子即可 | 完整跳切 |
| 工序式亲密 | **S** | 否 | 可选 | **必做** |
| 母题复现 | **S** | 否 | ≥2 次 | ≥3 次且**每次带新信息** + 结尾残缺化 |
| 第三方装置 | **S** | 否 | 是（点出被动） | 是（升格为全文脊梁） |
| 真实锚点 | B | 顺其自然 | 每场景 ≥1 | 每 300 字 ≥1 |
| 称呼陌生化 | B | 否 | 慎用 | 可用 |

**为什么分 S/A/B**：S 级是"签名招"——缺了会立刻露怯，读起来像事故复盘而不是这种文体。A 级构成骨架。B 级是装饰，可省。
标准档若时间有限，优先保住 S 级的"第三方装置"和"母题"，比堆数字有效。

## 二、九大技法（定义 / 示例 / 模板 / 触发）

> 以下示例句**仅用于说明机制**。生成时禁止复用这些句子、母题组合或情节节拍（见 SKILL.md 防换皮条款）。

### S1 · 工序式亲密【强】
- **定义**：把操作/照顾/修复行为拆成步骤，用"先X再Y最后Z"，冷感中透出温度。
- **机制示例**：「先是粗的那一面，磨完换一面，再换一面。磨一会儿举起来对着灯看看，再接着磨。」「这一面磨形状，这一面抛光，最后一面不要来回蹭，要顺着一个方向。」
- **模板**：`[主体]把我的[部位/对象]放在[位置]，[动作]。先是[工序1]，[工序2]，[工序3]，要[方向/禁忌]。`
- **迁移示范**（不同题材，仅共享机制）：「先是 R-Studio 扫分区，扫完举到屏幕前看一眼，再换 Windows File Recovery 扫一遍。先是快速，再深度，最后把认出来的文件名一个一个对着看。」
- **触发**：任何"手在动"的环节——照顾、教学、修复、整理、调试。
- **缺失后果**：全文从"织物质感"掉到"事件复盘"，是单项里最致命的失分。

### S2 · 母题复现与进化【标/强】
- **定义**：选 2-3 个意象隔段回扣。**每次回扣必须带新信息**，只重复同一含义的叫"复读"不是母题。
- **不及格**：图标出现三次都是"11个→消失→11个没回来"，含义没长。
- **及格**：「每死一个软件多一个白板图标」（新因果）→「比软件还多」（量变）→「其中一个是我上周建完就忘了的，它还在」（反讽 + 新信息 + 残缺化）。
- **模板**：开篇埋母题 A → 中段让 A 在异地/异物上重现 → 某次回扣带出新事实或新因果 → 结尾以"失效/残缺/反讽"形态收。
- **触发**：动笔前列"母题轨迹表"，逐次规划「位置 / 形态 / 这次带什么新信息 / 结尾如何残缺」。

### S3 · 第三方装置【标/强】
- **定义**：引入一个真实工具/系统作为"第三方判决"或"逃避代理"，替"我"做出本该自己做的决定。
- **进阶（强档必做）**：不只让它做决定，要**点透讽刺**——"删文件的是它，告诉我关机的也是它。我只是在旁边点了不知多少次允许。"把"决定权交出去"从背景升格为全文脊梁。
- **模板**：`[第三方]说，[本该由我做的决定]。[我照做了 / 我盯着那行字看了很久]。从头到尾，没有一个决定是我自己做的。`
- **用浅的征兆**：删掉第三方，故事照样能讲 → 说明它没起作用。

### A1 · 数字锚定【标/强】
- 定义：用具体数字替代形容词。
- 模板：量级对比 `[极小单位]的重量，[数字]。[极大单位]的重量，[数字]。`（两句必须**同量纲**才可比）；沉默量化 `[N]秒` / `[N]下`。
- **纪实轨必须用真实数字或模糊化**（见第三节改写协议），禁止编造。
- 触发：想写"很大/很久/很痛"时，先问"能换算成什么数字"。

### A2 · 对比倒置【标/强】
- 定义：把该当背景的捧成主体，把该当主角的按进背景。
- 模板：`[一堆大物]就像[一堆物]一样被请来做了陪衬，[他们不知道为什么出现]，[什么都没发生]。`
- 变体：尊严倒置（小人物"像讨论一项工艺"，大人物"不知道自己为什么出现"）；**权限倒置**（申请的是查看，干的是删除）。
- 触发：需要新鲜感时找一对"该大/该小"的关系反过来写。

### A3 · 冷叙述留白【轻/标/强】
- 模板：失态留白 `我没有[情绪词]。我一直在等自己[情绪词]。`；顿悟留白 `我想，原来是这样。`（≤8 字）
- **使用注意**：不要把两个同义钝感句堆在同一段（"懒得数"后紧跟"我没有慌"会显刻意），隔段使用。
- 触发：写到情绪顶点，强制删光形容词，只剩动作/数字/一句话。

### A4 · 非线性跳切【标/强】
- 先写"现在/结局"钩子 → 插叙早年起点（形成反差）→ 回到现在主体 → 高潮靠近结尾且极短。

### B1 · 真实锚点【可选】
- 可查的真实名词（品牌/地名/年份/型号）。虚构轨用来伪造真实感；纪实轨里天然存在，不用硬塞。
- **优先级最低**，不要为凑锚点破坏节奏。

### B2 · 称呼陌生化【可选】
- 让对方提出不合常理的称呼/规则，叙述者照做；称呼同时含顺从与掌控的矛盾。纪实轨慎用。

## 三、结构原则

**恒常原则（任何档位）**：篇幅与情绪成反比——高潮最短最轻，余韵最长最重；**结尾走母题收口，不走议论升华**。

**该砍掉的升华素材**：人生感悟比喻、时代感慨、身份自况、行动建议、点题金句。用户素材里这几类一律标记删除。

**结尾两条路**：
| | 母题收口（唯一正确） | 议论升华（禁止） |
|---|---|---|
| 做法 | 回到开头意象，以"失效/残缺/还在"形态收尾，不解释 | 拔高到人生/时代/道理，给感悟或建议 |
| 效果 | 判断权交给读者，余味长 | 说教感，张力泄掉 |

**五幕（仅强风格档）**：开头信息雪崩 → 回忆插入 → 现实主体 → 慢板细节 → 极短高潮 → 长余韵。轻度/标准档不必凑满五幕，守住"篇幅反比"即可。

## 四、原创协议（模式 B）

1. **定档**：轻 / 标准 / 强风格。
2. **锁人格**：写"我"的三条设定——资源层级、情感钝感表现、依赖谁/什么做决定。
3. **定核心事件**：选一个"交换/失去"事件做骨架，事件必须能换算成数字。
4. **列母题轨迹表**：2-3 个母题，逐次规划形态与新信息。
5. **写开头**：`[小单位数字] ↔ [大单位数字（同量纲）] ↔ [动机焊接]`，接 3-5 句事实雪崩（强/标准档）；轻度档可直接从事切入。
6. **写工序段**（强档必做）：挑一个操作场景写成 SOP。
7. **写极短高潮**：按 A3，同时坐实 S3 第三方装置。
8. **写长余韵**：回到母题，残缺化闭环。
9. **调性扫描**：搜一遍网络梗/俏皮话，删或抽梗保事实。
10. **评分自检**（见第五节）。

## 五、改写协议（模式 C · 含纪实轨）

1. **定档**：用户拿完整经历要"用这套写法改写" → 通常**标准**档。
2. **素材二分**：分成"叙事（发生了什么）"与"议论（你悟到了什么）"。**议论全部标记删除**——本类文体靠母题收口，不靠升华。
3. **数字标级**：把素材里每个数字标成 `[确切] / [约数] / [未知]`。未知的**立刻决定模糊化写法，不要填数**。
   - 策略：原文确切数 → 可验证的第三方数据 → 模糊化（"数到第二十几个就懒得数了""我懒得数"）。
   - 模糊化不是偷懒，它多交付一层钝感人格。
4. **挑母题**：找那个"反复出现、且能在结尾以失效/还在/忘了的形态回来"的物件或动作。判断标准：它本身是不是就是主题的隐喻？（例："软件没了但图标还在" = 完美的残缺化母题）
5. **找题材自带的第三方**：谁替"我"做了本该自己做的决定？这点往往就是全文最锋利的讽刺，升格为脊梁（S3）。
6. **挑操作场景写工序**（标准/强档）：扫描、恢复、整理、修复——任何"手在动"的环节。
7. **调性扫描**：抽掉网络梗与俏皮话（素材自带梗时保留事实、删掉梗）。
8. **评分自检**。

## 六、10 分制自检表（标准档与强风格档打分；轻度档只做定性检查，不打分）

| # | 项目 | 分值 | 满分标准 |
|---|---|---|---|
| 1 | **工序式亲密**（S） | 2 | 至少一段把操作写成 SOP：工具名 + 分步 + 观察动作 + 方向/禁忌 |
| 2 | **母题进化**（S） | 2 | ≥2 母题、≥3 次出现，**每次带新信息**，结尾残缺化或反讽化 |
| 3 | **第三方装置**（S） | 2 | 第三方替"我"做决定，且点透"决定权不在我手里"的讽刺 |
| 4 | 数字锚定（A） | 1 | 有同量纲量级对比；情绪换成计量单位；无空洞形容词 |
| 5 | 对比倒置（A） | 1 | ≥1 处倒置，且逻辑不生硬 |
| 6 | 冷叙述留白（A） | 1 | 高潮最平；有失态/顿悟留白句；未堆叠同义钝感句 |
| 7 | 结构节奏（B） | 0.5 | 篇幅与情绪成反比；有非线性跳切 |
| 8 | 句法纯度（B） | 0.5 | 几乎无"然而/但是/所以/因为"；关键反转用最短句 |
| 9 | 结尾纯净度（B） | 0.5 | 母题收口；无升华、感悟、建议、金句 |
| 10 | 调性统一（B） | 0.5 | 无网络梗/俏皮话；人格温度一致 |

**评级**：9-10 可交付（强风格档目标）；7-8 骨架成立、按缺失的 S 级补写（标准档目标）；≤6 重写。

**纪实轨一票否决项**（触犯直接判不合格，不计分）：
- [ ] 是否编造了素材中没有的数字？
- [ ] 是否编造了对话原话、他人行为细节、不确定的时间？
- [ ] 未知数字是否已走模糊化？

**评分输出格式**：
```
自评：X/10（档位：标准/强风格）
- 工序式亲密 X/2 —— 理由
- 母题进化 X/2 —— 理由
- 第三方装置 X/2 —— 理由
- 4-10 项合计 X/4 —— 一句话总结
纪实轨否决项：通过 / 触犯：xxx
下一步：可交付 / 需补哪几项
```

## 七、常见失分点 Top5

| # | 失分点 | 症状 | 药方 |
|---|---|---|---|
| 1 | **工序式缺失** | 读起来像事故复盘/工作日志 | 找一个"手在动"的场景，写成 SOP |
| 2 | **母题是复读不是进化** | 出现三次，读者没获得新信息 | 每次回扣安排新因果/新事实/新工艺/反讽 |
| 3 | **第三方用浅** | AI 只承担功能，不揭示人格 | 补一句点透被动 |
| 4 | **调性破洞** | 冷叙述里冒出网络梗/谐音梗 | 抽梗保事实 |
| 5 | **纪实轨编数字** | 为凑数字锚造出"47次""11个" | 走模糊化策略 |

## 八、反模式速查

- 用连接词串联 → 改句号硬断。
- 高潮处解释情绪 → 删形容词。
- 结尾讲道理/给建议 → 改母题收口。
- 不同题材写出来都一个样 → 降档，或换母题与人格。
- 换题材但读着像范文换皮 → 检查是否复用了原作的句子、母题组合、情节顺序（违反防换皮条款）。
- 堆形容词代替名词（"奢华的酒店"→ 具体酒店名）。
- 使用可指认的真实人物做虚构叙事。
