# cold-confession-prose

冷叙述忏悔录写作工艺。一种"用物理量代替形容词、用冷叙述代替抒情"的第一人称叙事文体 skill。

把《我的女友景甜》这类"富人第一人称忏悔录"体，拆成**可复刻的写法机制**——不是感悟式空话，而是带模板、带分级、带自检表的生成协议。

## 适用场景

- 明确要求写**冷叙述**、**数字化情绪**、**阶级反差**的叙事
- 要求分析"富人忏悔录"类特定叙事结构
- 复刻该文体的克制质感

**刻意不触发**：普通品牌故事、个人回忆录、一般新媒体软文——那些不该自动进入这套文体。

## 安装

git clone https://github.com/NEKOINEKOI/cold-confession-prose ~/.workbuddy/skills/cold-confession-prose

## 三模式

| 模式 | 触发 | 读取文件 |
|------|------|----------|
| A 分析 | "拆解/分析这类写法" | SKILL.md + analysis-guide.md |
| B 原创 | "用这套写法写一篇" | SKILL.md + generation-guide.md（+ examples.md 参考） |
| C 改写 | "把这篇改成冷叙述" | SKILL.md + generation-guide.md |

> 路由铁律：**生成与改写任务不读 analysis-guide.md**。读完整逐句拆解会让模型记住原句，退化成换皮复刻。

## 三强度档

| 档位 | 取用程度 | 适合 |
|------|----------|------|
| 轻度 | 冷静语气 + 动作留白 | 只想压一压抒情腔 |
| 标准 | + 数字锚定、母题复现、时间跳切 | 大多数场景 |
| 强风格 | + 完整五幕、高密度技法、所有签名招 | 追求极致质感 |

"母题须出现 ≥3 次""须五幕""第四句须动机焊接"等规则**只属于强风格档**，其余档位是可选强度，避免所有题材长成一个模子。

```

```

## 双轨与边界

- **虚构轨**：可用真实名词做"信任锚"伪造真实感，但须用不可识别的虚构人物，不得影射真人。
- **纪实轨**：写真实经历时，数字须为原文确切数或可验证第三方数；无法核实的改为模糊量级（"数到二十几就懒得数了"），**禁止编造精确数字**。
- **防换皮**：生成时不得复用参考作品的独特句子、人物关系、母题组合、情节顺序，只能复用抽象机制（克制、物理量、留白、回环）。

## 自检

写完按 generation-guide.md 末尾的 10 分制自评表打分，重点查三处签名招（工序式亲密、母题进化、第三方装置）是否到位，以及任何编造数字（一票否决）。
