# sun-ge-storytelling

孙ge故事写法——把一个平铺直叙的故事，改成孙哥那种讲法。

数字代替形容词，留白代替抒情，最疼的地方一笔带过，结尾不点题。

你给一段真事，它还一篇有质感的叙事。人称不变，事实不变，只换讲法。

## 改之前 / 改之后

素材原话：

> 更要命的是，明天就要给顾客的定制源文件也没了。

改完：

> 明天要交付给顾客的定制源文件，也没了。

只动了五个字。原稿在替读者着急，改完让读者自己急——这是这套写法最核心的一件事。

再来一段长的。素材：

> 前后用了两个恢复工具，一个是三方叫 R-Studio，另外一个是微软自己的 Windows File Recovery。所有流程都足够顺利，然后一打开才发现完全不是那么回事。好消息是所有文件都找回来了，坏消息是全都损坏了。

改完：

> 我用两个工具找回。先是 R-Studio 扫分区，扫完举到屏幕前看一眼，再换 Windows File Recovery 扫一遍。先是快速，再深度，最后把认出来的文件名一个一个对着看。
>
> 挖出来不少。全坏了。txt 是乱码，没有一个能打开。

一句"用了两个工具"拆成了工序；"好消息坏消息"那套转折整个删掉，只留结果。

完整的前后对照在 `references/examples.md`。

## 怎么用

把你的故事丢给 AI，说一句：

- "用孙哥那种语气改一下"
- "用孙ge故事写法改"
- "把这篇改成冷叙述"
- "帮我写一段有质感的叙事"（记得附素材）

没素材它不会自己编——会先问你要故事。

## 三档力度

| 档位 | 取用程度 | 适合 |
|------|----------|------|
| 轻度 | 冷静语气 + 动作留白 + 少量数字 | 只想压一压抒情腔 |
| 标准（默认） | + 数字锚定、母题复现、时间跳切、第三方装置 | 大多数改写 |
| 强风格 | + 完整五幕、高密度技法、所有签名招 | 追求极致质感 |

"母题须 ≥3 次""须五幕"这类规则只属于强风格档，其余档位是可选强度——不然所有题材都会长成一个模子。

## 它不会做的事

- **不凭空原创**：没素材先向你要。
- **不扩写**：成稿长度由素材决定，不为凑字数添加素材里没有的内容。
- **不编数字**：素材没给的数走模糊化（"数到第二十几个就懒得数了"）。约数也不精确化（"100 多 G"不能写成"103GB"）。
- **不议论升华**：结尾回到母题收口，不写人生感悟、时代感慨、行动建议、点题金句。
- **不套用现成句子**：禁止复用既有作品的独特句子、母题组合、情节顺序，只能用抽象机制。
- **不混网络梗**：冷叙述里冒出俏皮话会出戏，素材自带梗时抽梗保事实。

## 有自己的口吻？用混合版

纯冷叙述会把你本人的声音磨掉。如果你是有固定口语人设的自媒体作者，用**混合版**：

- **保留骨架**：数字锚、母题回环、第三方装置、篇幅反比、母题收口结尾、工序段落
- **放回口吻**：语气词、你的梗、短评价、与读者的互动
- **不放回**：长篇议论与升华、解释情绪（这两条是红线，混合版同样适用）

判据一句话：**删掉所有口吻词后，剩下的仍应是一段合格的冷叙述。**

具体做法见 `rewrite-protocol.md` 附录 A。
