# cold-confession-prose

**这个 skill 是干啥的**：你有一段自己的故事（真实经历、发生过的事、一篇已有文稿），交给它，它帮你**改成《我的女友景甜》那种克制、冷调、有质感的叙事风格**。

你给素材，它出稿。不换人称，不改事实，只换讲法。

**它是转换器，不是写作教材。** 没给素材就让它凭空写一篇——那不是它的用途，它会先向你要故事。

## 怎么用

把你的故事丢给 AI，说一句：

- "用冷叙述风格改一下"
- "用《我的女友景甜》那种写法改"
- "帮我写一段有质感的叙事"（附上素材）

## 输入 → 输出

| 你给 | 它还 |
|------|------|
| 一段真实经历 | 冷叙述版的同一段经历 |
| 一篇已成稿的叙事文 | 同素材的冷叙述重写 |
| 一个虚构故事设定 | 冷叙述版的同一故事 |

具体长什么样，看 `references/examples.md` 里的**改写前后对照**。

## 强度三档

| 档位 | 取用程度 | 适合 |
|------|----------|------|
| 轻度 | 冷静语气 + 动作留白 + 少量数字 | 只想压一压抒情腔 |
| 标准（默认） | + 数字锚定、母题复现、时间跳切、第三方装置 | 大多数改写 |
| 强风格 | + 完整五幕、高密度技法、所有签名招 | 追求极致质感 |

"母题须 ≥3 次""须五幕"这类规则**只属于强风格档**，其余档位是可选强度，避免所有题材长成一个模子。

## 文件结构

```
cold-confession-prose/
├── SKILL.md                     入口：定位 + 主流程五步 + 强度档 + 六条红线
└── references/
    ├── rewrite-protocol.md      主文件：改写八步 + 10 分制自检表
    ├── techniques.md            技法库：九招（S/A/B 分级）+ 模板 + 迁移示范
    ├── examples.md              改写前后对照（原稿 → 成品）
    └── analysis-guide.md        仅分析模式读：范文逐句拆解
```

> 路由铁律：**改写任务不读 analysis-guide.md**。读完整逐句拆解会让模型记住原句，退化成换皮复刻。

## 它不会做的事

- **不凭空原创**：没素材先向你要。
- **不扩写**：成稿长度由素材决定，不为凑字数添加素材里没有的内容。
- **不编数字**：素材没给的数走模糊化（"数到第二十几个就懒得数了"）。约数也不精确化（"100 多 G"不能写成"103GB"）。
- **不议论升华**：结尾回到母题收口，不写人生感悟、时代感慨、行动建议、点题金句。
- **不复用范文**：禁止复用参考作品的独特句子、母题组合、情节顺序，只能用抽象机制。
- **不混网络梗**：冷叙述里冒出俏皮话会出戏，素材自带梗时抽梗保事实。

## 自检

改写完按 `rewrite-protocol.md` 末尾的 10 分制表打分，重点查三处签名招（工序式亲密、母题进化、第三方装置）是否到位，以及任何编造数字（一票否决）。
